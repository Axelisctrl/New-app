Keep your history.
Keep your momentum.

ChatCooler is designed to help long conversations remain responsive by reducing how many message elements the page renders at once, while keeping older messages accessible.

▤

Keep older messages

The concept preserves the full sample history and lets you move through it in smaller windows instead of permanently deleting older messages.

↗

Render less at once

Compare displaying all 300 message blocks with displaying a smaller window. Fewer rendered elements may reduce some browser rendering work.

⌁

Designed for long sessions

The idea is to help people keep learning and writing on older laptops without abandoning long conversations just because the page becomes slow.

See the idea in action

Load a long sample conversation, switch ChatCooler on and off, and navigate between older and newer parts of the history. The counters show how many message elements this demo currently renders.

Prototype disclosure: This is a standalone demonstration of a rendering approach. It is not the real ChatGPT service, is not connected to a live AI model, and does not prove a measured speed improvement on real devices or other websites.

What this demonstrates: With ChatCooler OFF, the page creates a DOM element for every message. With ChatCooler ON, it displays a window of up to 22 messages at a time; the remaining messages stay in the page's JavaScript history and can be shown using the earlier/later controls.

What this doesn't prove: This prototype does not measure CPU usage, memory use, typing delay, or scrolling performance on a real low-powered laptop. It also does not modify the real ChatGPT, Google Docs, or other websites.
Transparency and privacy

Privacy Policy

Effective date: October 24, 2026

This policy explains how the ChatCooler demonstration website handles information. ChatCooler is a prototype exploring ways to reduce the number of message elements rendered at one time in a long conversation.

1. Information handled by this demo

The sample conversation is generated in your browser. Messages you type into this demonstration and the generated sample history are held in the page's JavaScript memory for the current session. This demo does not send your message text to a ChatCooler server or to an AI provider.

2. Storage and cookies

This single-page demo does not intentionally set cookies, use analytics scripts, or save chat messages to a ChatCooler account. The conversation in this demo is not designed to persist after the page is refreshed or closed.

3. Third-party services

This page does not intentionally load third-party analytics or advertising scripts. If the page is hosted using GitHub Pages, GitHub may process technical information such as server logs as part of operating its hosting service. Refer to GitHub's Privacy Statement for information about GitHub's handling of data.

4. The separate browser extension

This page is a demonstration website, not the ChatCooler browser extension. The extension's actual data practices depend on its code, permissions, and configuration. Before this policy is used as the official policy for a distributed extension, the developer must verify that the extension behaves consistently with this policy.

If a future version stores preferences, sends data to a server, integrates with an organization, or uses any external service, this policy must be updated to clearly describe that behavior before release.

5. Purpose of processing

The purpose of this demonstration is to show a rendering approach: keeping message history available while rendering a smaller number of message elements at a time. Sample content is provided only to demonstrate that interface.

6. Children's privacy

This prototype is not specifically directed to children and does not ask visitors to submit personal information.

7. Policy changes

This policy may be revised when the website or product changes. The effective date at the top should be updated when a material revision is made.
